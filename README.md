# QS Click

Быстрые снимки экрана для Windows: выделил область — сразу разметил и сохранил или скопировал в буфер.

Программа рассчитана на всех, кто регулярно делает и размечает скриншоты: разработчиков, тестировщиков, сотрудников технической поддержки и авторов документации.

## Возможности

- Снимок области мышью, активного окна, всего рабочего стола или отдельного монитора.
- Встроенный редактор: стрелки и линии, текстовые подписи, прямоугольники и эллипсы, маркер-подсветка, размытие, обрезка, нумератор.
- Копирование в буфер обмена или сохранение в PNG/JPEG.
- Глобальные горячие клавиши с настраиваемыми комбинациями.
- Работа из области уведомлений, автозапуск с Windows, единственный экземпляр приложения.
- Поддержка нескольких мониторов, в том числе с разным масштабом DPI.

## Быстрый старт

Клонируйте репозиторий и соберите проект в Delphi.

```powershell
git clone https://github.com/<ваш-аккаунт>/<репозиторий>.git
```

Дальше в Delphi 13:

1. Установите **Delphi 13 (RAD Studio)** с платформой **FireMonkey** для Windows.
2. Откройте проект `1-QuickScreen\QS_Click.dproj`.
3. Выберите платформу **Windows 32-bit** или **Windows 64-bit**.
4. Выполните `Project → Build`, затем `Run → Run` (или `F9`).

Тот же этап из командной строки:

```powershell
msbuild QS_Click.dproj /p:Config=Release /p:Platform=Win32
```

После сборки в каталоге `Win32\Release\` появится `QS_Click.exe` — запустите его.

> **Зависимость (необязательная):** страница «О программе» на Win32 использует просмотрщик Markdown `Markdown4D.Fmx`. Если пакет не установлен, добавьте в условные символы проекта символ `QS_NO_MARKDOWN4D` и уберите `Markdown4D.Fmx` из Runtime Packages — страница «О программе» перейдёт на обычный `TMemo`, остальное не изменится.

## Использование

После запуска приложение живёт в области уведомлений. Захват по умолчанию:

| Комбинация | Результат |
|---|---|
| `Ctrl+Shift+1` | снимок области — выделите нужный участок мышью |
| `Ctrl+Shift+2` | снимок активного окна |
| `Ctrl+Shift+3` | снимок всего рабочего стола |

Готовый снимок открывается в редакторе. Управление в редакторе:

| Действие | Результат |
|---|---|
| `Ctrl+S` | сохранить в файл |
| `Ctrl+C` | скопировать в буфер обмена |
| `Ctrl+Z` / `Ctrl+Y` | отменить / повторить |
| `Ctrl+0` | масштаб 1:1 |
| `Esc` | закрыть редактор |

Пример запуска из командной строки:

```powershell
Start-Process .\Win32\Release\QS_Click.exe
```

Ожидаемый результат — в трее появляется значок QS Click, горячие клавиши активны, повторный запуск не создаёт второе окно, а показывает уже работающее.

## Конфигурация

Переменные окружения не требуются. Параметры программы хранятся в файле `settings.ini` (папка `%USERPROFILE%\QS Click`) и редактируются из окна «Настройки» приложения.

| Параметр | По умолчанию |
|---|---|
| Формат сохранения | PNG |
| Качество JPEG | 92 |
| Горячие клавиши снимков | `Ctrl+Shift+1`, `Ctrl+Shift+2`, `Ctrl+Shift+3` |
| Открывать редактор после снимка | да |
| Автозапуск с Windows | выключен |
| Параметры инструментов редактора | запоминаются в `[Editor]` секции `settings.ini` |

Текст страницы «О программе» берётся из файла `about.md`, расположенного рядом с исполняемым файлом и создаваемого автоматически (скрытого и только для чтения). В дистрибутив файл можно включать уже готовым — программа не перезапишет его, но выставит атрибуты «скрытый» и «только для чтения» при первом запуске.
